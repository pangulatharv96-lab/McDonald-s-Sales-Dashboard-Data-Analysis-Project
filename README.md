# McDonald-s-Sales-Dashboard-Data-Analysis-Project
- Project Overview
  - This project analyzes McDonald’s sales performance using Microsoft Excel and presents insights through an interactive dashboard.
  - The dashboard helps understand overall sales, profit, and customer performance   while comparing actual results against targets.
  - The objective is to provide a clear, visual summary of McDonald’s business performance that can support managerial and operational decision-making.

-----------------------------------------

- 🎯 Objectives
  - Evaluate McDonald’s overall sales and profitability
  - Compare Actual vs Target performance
  - Track customer growth and performance
  - Present insights in a simple, interactive dashboard

----------------------------------------

- 📁 Dataset Description
  - The dataset contains McDonald’s sales-related data, including:
  - Sales (Actual & Target)
  - Profit (Actual & Target)
  - Customer count (Actual & Target)
  - Category-wise sales information
  - Data is cleaned and structured using Excel for accurate analysis.

----------------------------------

- 📌 Key Performance Indicators (KPIs)
  - Total Sales – Actual vs Target
  - Total Profit – Actual vs Target
  - Total Customers – Actual vs Target
  - These KPIs give a high-level snapshot of McDonald’s performance.

-----------------------------------------

- 📈 Dashboard Features
  - Pivot Tables for quick data summarization
  - Bar Charts to compare actual vs target metrics
  - Pie Charts to show percentage contribution by category
  - User-friendly layout suitable for presentations and reports

-------------------------------------------

- 🛠 Tools & Technologies
  - Microsoft Excel
  - Pivot Tables
  - Bar & Pie Charts
  - Dashboard Design

---------------------------------------

- 🔑 Key Insights
  - Actual sales and profit performance compared to business targets
  - Category-wise contribution to total sales
  - Customer performance trends
  - Visual comparison helps quickly identify gaps and strengths

---------------------------------------

- 🚀 How to Use
  - Download the Excel file from the repository
  - Open the Dashboard sheet
  - Interact with charts and pivot tables to explore insights

----------------------------------------------------

- 📌 Conclusion
 - This McDonald’s Sales Dashboard demonstrates strong data analysis, Excel, and visualization skills.
 - It shows how business data can be converted into actionable insights using dashboards designed for real-world decision-making.
